Connect to GitHub

Saving writes players.json straight to the repo, so you need a GitHub token that can write to it. The token is kept in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Under Repository access choose Only select repositories and pick this repo.
  3. Under Permissions set Contents to Read and write.
  4. Generate the token and paste it here.

Can't pick the repo in step 2? It belongs to someone else. The README explains how friends get write access.
